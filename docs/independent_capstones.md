# 手順を自分で選ぶ総合課題（L10）

「ヒントなし総合課題」に2課題を追加します。共有する修正と手元の下書きを分ける課題と、共有済みの不具合を履歴を残して取り消しつつ手元の作業を守る課題です。既存の手順付き総合演習を準備として案内します。

達成前は4段階のヒントを表示せず、達成条件とGitの状態から操作を選びます。達成後に解答例と説明を表示します。解答例を読んでもヒント利用記録は増やしません。やり直し・再読込で初期状態へ戻すと解答例を再び隠します。一般の演習は従来の段階ヒントを維持します。

採点は共有先・作業ツリー・実効index・履歴・作業ブランチ等の状態で行います。特定の解答文字列に固定せず、確認済みの別解を受け入れます。全ファイルを一括stageして私的下書きまで公開、共有履歴をresetして削除、手元のメモを喪失した場合は未達です。

これはブラウザの学習UIでヒントを表示しない機能です。解答データはクライアントにも含まれ、試験の不正防止や解答の秘匿は目的にしません。

新IDを追加し、既存演習IDと保存version 1を維持します。新IDの完了/途中状態は旧版のカタログでは対象外です。L10はこの2課題の範囲で完了し、任意の業務シナリオすべてを網羅した意味ではありません。
