# 誤操作を診断して直す課題（L08）

「誤操作からの復旧」に3課題を追加しました。いずれも独立した初期状態から始まり、考え方・確認方法・コマンド候補・解答例を段階的に参照できます。

| 課題 | 初期状態の問題 | 完了条件 |
| --- | --- | --- |
| mistake-stale-index | Draftをstageした後、作業ツリーをFixedへ再編集 | FixedとKeepを記録し、追跡ファイルをクリーンにする |
| mistake-wrong-branch | 共有前のmainに必要なコミットを誤記録 | featureでc2を保護し、mainをc1へ戻してfeatureで作業する |
| mistake-stale-approval | 修正後c3へpush済みだが、承認・CIはc2の記録 | 最新版を確認してmainへマージし、Reviewed fixとKeepを残す |

古いindexのままcommit、mainを戻すだけ、レビューだけを更新してCIを更新しない操作は未達です。既存の正常手順の反復と分け、最初からある不整合を見つけて修正する課題です。

mainの巻き戻しは共有前のローカル課題だけに限定します。実GitHubの承認失効条件は保護設定に依存し、この模擬環境の「最新コミットへの承認・CIが必要」という条件とは区別します。任意の誤操作をすべて網羅した意味ではありません。

参照解答・不正解・全教材の共通採点/保存境界テストと、各課題のブラウザ完了・完了記録の再読込を検証します。
