## 保存と互換性

従来のversion 1完了・ヒント・選択を維持し、同じnamespaceに`session:<演習ID>`を追加する。全削除は自由練習のcheckpointも含める。演習ごとの削除はその演習のcheckpointも削除し、現在のGitには触れない。明示保存の再実行で前のcheckpointを置き換える。

バックアップは`git-learning-backup` version 1。5MB以下、既知の演習/コース/キー、記録の型・サイズ・参照・非循環履歴・入れ子深さを検証する。未知形式を勝手に上書きしない。取り込み前に件数・上書き範囲を表示し、明示ボタンで確定する。対象外キーを削除しない。途中失敗は書き込み済みの値を戻し、別タブの新しい値を保護し、戻し失敗も通知する。

バックアップにはユーザーが入力したコマンドやファイル内容が含まれる。外部送信はしない。保存が失敗した未保存データはexport対象外のため、先に再試行する。操作途中の演習移動・初期化は引き続き画面に説明する。
