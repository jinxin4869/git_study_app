## 追加機能の使い方

- 端末の「端末出力をコピー」で、押した時点の出力をコピーします。権限拒否時は表示された欄から手動で選択できます。
- 「入力補完・履歴検索」で候補を選ぶと入力欄へ移ります。末尾の候補が一つならTabでも補完できます。内容を確認してEnterで実行します。
- グラフのボタンで倍率と表示位置を変え、コミットの選択欄でメッセージ・親・第一親との差分ファイルを確認できます。閲覧操作はGitの状態を変えません。
- ファイル一覧の作成ボタンとプレビューの編集ボタンで作業ツリーを変更します。stageは別操作です。古い編集の上書き・同名作成・ファイル/フォルダの衝突を拒否し、削除には確認があります。演習切替や閉じる操作で未保存の下書きは破棄します。
- `npm run test:coverage`は単体テストの実行範囲を測ります。ブラウザE2Eや実Gitラボを合算した率ではありません。
- 計測・移植元記録・Draft・cleanの対応構文と制約は、上の関連文書と各PRを参照してください。
