## 用意する環境

普段の学習記録を消さないよう、専用の新規ブラウザプロファイル等で確認する。実機SafariはMacまたはiPhone/iPad、実読み上げはVoiceOver/NVDA等、ソフトキーボードはiPhone/iPadまたはAndroidで確認する。利用できた組合せごとに結果を残し、他の端末まで検証済みとはしない。保存確認には永続保存を許可したプロファイルを使う。

最初に「学習コース」を「すべてのコース」にして「演習を検索」から指定演習を選ぶ。ブラウザ・OS・IME・読み上げソフトの版、向き、ページズーム倍率、確認日時、公開SHAを記録する。公開版が変わった場合は[runbook](release_runbook.md)でdeployment/SHAを確認してから実行する。

### M04の保存失敗を再現する方法

専用のテストプロファイルで `/game` を開き、開発者コンソールが利用できるPCで次を1回実行する。アプリ用キーの書込だけを、そのページ内で一時的に拒否する。実容量を使い切った試験やブラウザ設定による拒否の代用とはしない。

```javascript
(() => {
  const original = Storage.prototype.setItem;
  Storage.prototype.setItem = function (key, value) {
    if (String(key).startsWith('git-learning:')) {
      throw new DOMException('manual save failure', 'QuotaExceededError');
    }
    return original.call(this, key, value);
  };
  window.restoreGitLearningStorageWrites = () => {
    Storage.prototype.setItem = original;
    delete window.restoreGitLearningStorageWrites;
  };
})();
```

演習を達成して保存警告を確認したら、同じページのコンソールで `window.restoreGitLearningStorageWrites()` を実行する。アプリの「保存を再試行」を押し、警告が消えたことを確認してから再読込する。ページを先に閉じると未保存の完了は失われる。使ったプロファイルを後から破棄し、普段の学習記録は削除しない。
