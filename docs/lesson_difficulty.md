# 難易度の編集基準（L06）

追加課題の一律advanced分類を見直しました。変更対象の49課題を`src/learning/lesson-difficulty.ts`に明記し、カタログで表示メタデータだけを適用します。元の課題・初期状態・採点・保存ID・学習順は変えません。

| 分類 | 判断の基準 | 例 |
| --- | --- | --- |
| 初級 | 対象が明示された一つの領域を観察・基本設定する | status、diff、履歴/一ファイルの確認、作者設定 |
| 中級 | 記録と作業状態、参照、共有先の違いを選んで一つの目的を達成する | stash対象の選別、PR作成/確認、タグ、worktree準備 |
| 上級 | 履歴の書き換え・分岐後の統合・競合・複数段階の判断を組み合わせる | rebase、push拒否からの統合、対話的rebase、総合課題 |

コマンド数やファイル名のadvancedでは自動判定しません。PRの確認と修正後の再チェック、bisect開始と原因の絞り込み等を区別します。未変更の分類も既存の編集判断として維持します。特定の初期状態での練習の難易度であり、そのコマンドの全用途が簡単という意味ではありません。

所要時間の3〜5/5〜10/10〜20分は**未計測の目安**です。難易度の見直しだけで実測済みにはしません。利用者の所要時間の収集・測定は今回実施していません。L06は探索と難易度再分類の範囲を完了し、所要時間の実測は一部未完了として残します。
