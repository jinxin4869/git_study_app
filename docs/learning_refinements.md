## スクロールと動き

旧版の公開画面で `git status` を18回実行し、過去ログへスクロールして新しい出力を追加した。PCではログが0から1337pxへ、390px幅ではログが0から1792pxへ、ページ全体が0から719pxへ動いた。再現の一時記録は `/tmp/git-study-scroll-probe.cjs`。

`TerminalOutput`は端末のviewportのscrollTopだけを変更する。末尾から24px以内では新しい出力へ追従し、それより上を読むと停止する。過去ログ中に出力が追加されるとボタンに新しい出力があることを表示する。「最新の出力へ戻る」で再開する。ボタンは常に残してフォーカスを失わせない。端末全体のaria-liveは使用しない。

演習選択・やり直し・自由練習・clearは新しい端末セッションとして追従を再開する。ヒント・前提・解説の展開ではセッションを変えない。文字サイズ・viewportの変更時も、末尾閲覧中だけResizeObserverで位置を合わせる。説明/操作案内は端末内の利用可能高さの60%までの独立スクロールとし、ログと最新ボタンの領域を確保する。出力追加でページや情報パネルの位置は変更しない。スクロールは即時移動し、行ごとの入場アニメーションを除いた。

ホーム・達成表示・SVGグラフはuseReducedMotionで初期アニメーションを省き、transitionを即時にする。CSSの動き・hover拡大・smoothスクロールもprefers-reduced-motionへ対応する。紙吹雪の既存設定を維持する。

## 全139件の教材と採点

`lesson-notes.ts`に各演習の考え方、具体的な確認場所、実務上の注意/模擬範囲を個別に記述した。最初のヒントは閉じ、考え方→確認方法→操作候補→解答例の順を維持する。完了後は考え方と注意を表示し、達成時の共通assessmentの条件を保存して説明する。達成後の自由操作で現在の状態が変わっても、達成時の説明と混同しない。

`learning-path.ts`は基本操作から総合演習までの推奨順と準備演習を定義する。前提は理解を助ける案内で、完了を必須にしない。各演習は独立した初期状態から始まる。次のおすすめは現在より後の未完了演習を順に探し、後がすべて完了なら前の未完了へ戻る。自由選択を維持する。

13件の誤操作経路を修正前の採点で再現し、期待する不合格テストがすべて失敗した（`/tmp/git-study-grading-before.log`）。対象は別ファイルのコミット、違う作業ブランチ、違うDetached HEAD、目的別分割ができていない履歴、空のPR説明、CI/修正依頼を確認する前の終了。既存の条件に対象・参照・中間コミット内容・指定した確認操作を追加し、合格条件を弱めない。

HEAD/index/作業ツリー・親・履歴・最新レビュー/CIの述語は引き続き採点と条件表示で共有する。未知の採点キーは無視せず未達にする。GitHubのtreeはローカルHEADでなく模擬PRの統合先だと表示する。別解は実行と最終状態を検証したものだけをテストへ追加する。実Gitにあるすべての別解を保証しない。

## 保存と入力

保存形式version 1とキーは変更しない。未保存ヒントは再挑戦時も最大段階をメモリに保持する。保存領域へのアクセスが回復した際の再試行では既存の完了記録も再読込して一覧へ反映する。選択を保存できない場合も通知する。Gitの途中状態・端末履歴・ファイル内容は保存しない。

rebase todoにも入力の自動訂正等を無効化し、文字サイズを16pxへ合わせる。コマンドへのスキップリンクを追加する。グラフはコミットの親とブランチ/HEADの位置をSVGのテキスト代替として持つ。操作UIとホームを日本語へ統一し、実Gitではなく模擬環境であることを明示する。

## 入力拒否・例外復旧の追加点検

基点では `git log --not-a-real-option`、`git diff --not-a-real-option`、`git init --not-a-real-option`、閉じない引用符を含むecho、模擬reviewへの不明フラグが成功することをシミュレーターで再現した。初期化や確認操作を学ぶ課題は、不正オプションを無視した成功で合格し得た。一時証跡は `/tmp/git-study-input-before.log`。

`command-input.ts`はシェルではなく、引用符付き/空白入りの文字列、単一引用符、二重引用符内の引用符/バックスラッシュ、外のescapeと `echo >` を扱うliteral tokenizer。未完の引用符/escape、未対応の `>>`、pipe、コマンド連結、入力リダイレクトは拒否する。引用符内の `>` は文字として保持し、引用符を内容から二重に削除しない。変数・glob・コマンド置換は展開せず、外部プロセスは実行しない。任意シェル/全Git構文の互換性は保証しない。

既存status/commit/switch/rmの詳細validatorを維持し、主要Gitと模擬GitHubコマンドの対応フラグを実行前に確認する。logの無視された余分な参照/不足したgrep値も拒否する。restoreの `--source 値` を既存 `--source=値` と合わせる。全位置引数の再設計は行っていない。追加点検で `gh pr view 1 > output.txt` と模擬reviewが未対応のリダイレクトを無視して成功することを再現したため、echo以外の出力リダイレクトを実行前に拒否し、4経路で無変更/不合格を検証した。

executeの途中、例えばコミット更新後に例外が起きた場合は、直前のGitスナップショットとrevisionへ戻し、不合格と復旧案内を返す。障害注入で完全復元を確認し、直後の正しいcommitが実行できることも検証した。競合の意図した停止は、通常の例外や拒否と区別して既存の状態変更を維持する。不正な外部GitStateをconstructor/loadStateへ渡すAPI契約全体は今回の対象外。

実Gitとの追加比較は一時ディレクトリ内のみ。10種の未知flagを双方が拒否し、HEAD・作業内容・statusを保つこと、実シェル/Gitと引用符のあるメッセージ・空白パスが一致することを確認した。このアプリのechoに末尾改行を付けない違いは比較で明示する。

## E2Eで見つかった問題と対応

- 自由練習→基本操作や検索外のおすすめへ移ると、検索に隠れて選択中の演習を見つけられなかった。選択先が一覧にない場合は絞り込みを解除し、新しい選択/条件を保存する。
- 空のグラフ案内がaxeのcolor-contrast基準を満たさなかった。既存暗色パネルの文字をgray-400へ変更し、ホーム/ヒント/達成/競合/保存失敗の5状態で再検査した。
- 別タブのstorageイベントでlocalStorageへのアクセスが取り消されると、イベントハンドラーで例外になり得た。getter失敗を捕捉し保存警告を出し、現在の演習/完了を保持して再試行可能にした。
- 最初のPC/小画面の表示確認で、長い解説が小画面のログと最新ボタンを押し出した。説明/操作案内を独立スクロールへ分離し、長い解説中も出力80px以上と最新ボタンが入力より上にあることをE2Eへ追加した。
- 日本語UIへの変更に合わせ、既存E2Eの動的なAccept/Cancelラベル、状態凡例、追加入口ボタンを含むTab順を更新した。検証をskipせず同じ操作/寸法/コントラスト/フォーカス条件を維持した。
- 公開smoke初回はテスト側の演習タイトルと競合開始手順が不正確だった。教材の正しいタイトルと `git rebase main` の停止を先に実行する手順へ修正し、PC/390px幅の8件が成功した。
