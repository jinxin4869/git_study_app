# 未追跡ファイルの削除候補を確認する

`git clean -n`または`git clean --dry-run`で、追跡されておらず、ignoreされていないファイルの候補を表示できます。実際のファイル削除は行いません。`-d`を併用すると、追跡ファイルのないディレクトリ内も候補に含めます。`-nd`/`-dn`も同じです。

```text
git clean -n
git clean --dry-run -d
```

候補は引用符で囲んだファイル単位で表示します。実Gitはディレクトリ全体を一行へまとめる場合がありますが、この模擬環境は空ディレクトリを持たないため表示の粒度が異なります。`-d`なしでは、各親ディレクトリにindex上の追跡ファイルがある場合だけ、その中の未追跡ファイルを候補にします。

HEAD/index/作業ツリー、stash、履歴、進行中の操作を変更しません。stageされたファイル、未解消パス、ignoreファイル、`.git`メタデータ、登録済みsubmodule、`.git`パスで認識できる入れ子のリポジトリは候補から除きます。

`-f`/`-x`/`-X`/`-i`、実削除、パスの指定は未対応として拒否します。実Gitには追加の構文・削除機能がありますが、このアプリの対応範囲ではありません。詳細は[Git公式のclean](https://git-scm.com/docs/git-clean)を参照してください。ローカルの実Gitでも、既定では未追跡ディレクトリへ入らず、ignoreを除き、dry-runで内容を保持することを比較しています。

G09のうち削除前の確認を部分対応します。未コミット変更を失った後の復元、全体の復旧限界教材、実リポジトリの掃除を代行する機能は追加していません。
