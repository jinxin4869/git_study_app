# 復旧できる内容・できない内容（G09）

操作リファレンスに比較と3問の理解度チェックを追加しました。既存のコミット/ブランチ救出演習へ移る入口と、cleanのdry-runを合わせて学びます。確認問題への回答は演習の完了やGitの状態を変更しません。

コミットした版と、その後に未コミットで編集した版を区別します。reflogからコミットを保護できても、未記録の最新版が戻るとは保証しません。reflogの期限・オブジェクト削除もあり、模擬環境で古いコミットを保持することを実Gitの永久復旧と混同しません。

dry-runは削除候補の表示で、バックアップではありません。必要な未追跡ファイルは削除前に別に保管して判断します。このアプリはcleanの実削除を実装しません。checkpointも最後に保存した模擬状態だけを再開し、保存後の編集や実リポジトリは対象外です。

出典：[Git公式reflog](https://git-scm.com/docs/git-reflog)、[Git公式clean](https://git-scm.com/docs/git-clean)。外部教材の引用ではなく、模擬環境と実Gitの制約を説明します。

記録済みコミットは救出できる一方、未コミット編集はコミット履歴に現れないことを自動テストで確認します。ブラウザでは誤答/正答・やり直し・既存救出演習への移動を検証します。
